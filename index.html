01 적용 범위

이 방침은 WoodyyVerse가 개발한 iPhone·iPad용 헬스운동관리 앱의 개인정보 처리와 운동 기록 보관에 적용됩니다. 아래 내용은 현재 앱의 기능을 기준으로 설명합니다.

02 앱의 개인정보 수집

헬스운동관리는 회원가입이나 로그인을 요구하지 않습니다. 로그인하지 않을 때 운동 기록은 기기에 보관됩니다. 이번 1.4 제출 버전은 로그인·동기화를 제공하지 않으며 운동 기록을 개발자 서버로 전송하지 않습니다.

앱에서 이름, 이메일 주소, 전화번호, 위치 정보, 연락처, 사진 또는 광고 식별자를 수집하지 않습니다. 광고·이용 분석·사용자 추적 SDK를 사용하지 않으며, 1.2 이상 버전의 선택적 심박수 기능은 아래 설명과 같이 HealthKit을 사용합니다. 1.0·1.1에는 심박수 기능이 없습니다.

03 기기에 저장하는 기록

운동 측정과 기록 확인, 앱 재실행 후 복원을 위해 다음 정보를 앱 전용 저장 공간에 보관합니다.

  • 운동 날짜, 시작·종료 시각, 운동 종목·부위·기구
  • 세트별 중량·운동시간·세트 사이 휴식시간, 누적 운동시간과 휴식시간 (1.4부터 수행 횟수·웜업 여부와 수정된 기록 포함)
  • 사용자가 직접 추가한 운동과 즐겨찾기한 운동
  • 1.3 이상 버전: 사용자가 입력한 헬스장 이름·운동 목록, 슈퍼세트 이름·순서·반복 여부, 종목별 선택 중량·최대 중량
  • 진행 중인 운동·휴식 타이머와 일시정지 상태, 준비 시간·횟수 상한·잠금화면 표시 설정 (1.4에서 휴식 종료 예약 삭제)

Apple Watch 연동을 지원하는 1.1 이상 버전에서는 선택한 운동명·중량 또는 운동강도·선택적 속도·해당 운동의 세트 및 타이머 상태를 페어링된 Apple Watch에 전달하고, 워치의 시작·세트 종료·일시정지·재개 요청을 iPhone에서 처리합니다. 이 연동은 Apple WatchConnectivity를 사용하며 개발자 서버로 전송하지 않습니다. 전체 운동 이력이나 즐겨찾기 목록은 워치에 보내지 않습니다. 칼로리·위치·운동 경로는 수집하지 않습니다. 지원 기능은 설치된 앱 버전에 따라 다릅니다.

잠금화면 타이머(1.4부터): 실시간 현황이 허용되어 있으면 진행 중인 운동명·세트 번호·운동/휴식/일시정지 상태와 경과 시간을 iOS 잠금화면에 표시합니다. 잠금 해제 없이 보일 수 있으며 앱의 타이머 설정에서 표시를 끌 수 있습니다. 이 기능에 심박수·전체 이력·계정 정보는 포함하지 않으며 개발자 서버나 푸시 서버로 전송하지 않습니다. 운동 완료 또는 표시 끄기를 선택하면 실시간 현황을 종료합니다.

선택적 심박수 기능(1.2 이상 버전, 출시 별도): 워치에서 ‘심박수 사용’을 켜고 건강 권한을 허용하면 HealthKit 운동 세션으로 현재 심박수를 읽습니다. 측정값과 측정 시각·현재 운동 식별자를 WatchConnectivity로 페어링된 iPhone에 전달해 화면에 표시하고, 준비·일시정지를 제외한 운동 중 최대값과 휴식 중 최대값을 해당 운동 기록에 저장합니다. 연결이 끊기면 전송을 대기했다가 다시 전달할 수 있습니다. 앱은 전체 심박수 시계열을 기록 파일에 저장하거나 개발자 서버·광고·분석 서비스로 전송하지 않습니다.

심박수 읽기와 운동 세션 권한을 요청하지만, 별도 운동 기록을 Apple 건강·피트니스 앱에 저장하지 않습니다. 건강 설정에서 심박수 권한을 변경할 수 있습니다. 1.6부터 운동 기록에서 연결에 동의하면 Apple Watch 운동하기의 운동 시간과 심박수를 건강 앱에서 읽어 달력에 표시합니다. 이 데이터는 기기에서만 조회합니다. 권한을 허용하지 않아도 타이머·기록 기능은 사용할 수 있습니다. 표시값은 운동 참고용이며 의료 진단·치료용이 아닙니다.

이 정보는 운동시간 계산, 날짜별 캘린더 표시, 즐겨찾기 정렬과 진행 상태 복원에 사용됩니다. 1.3 이상 버전의 운동 그래프는 저장된 완료 기록의 시간·중량·심박수 최대값과, 1.4부터 세트별 중량×횟수로 계산한 총 볼륨·웜업 제외 볼륨을 기기에서 집계합니다. 헬스장 설정은 사용자가 직접 입력하며 위치 정보를 수집하지 않습니다. 기능은 설치한 앱 버전에 따라 다를 수 있습니다. 이번 1.4 제출 버전은 완료 기록과 진행 중 타이머를 모두 기기 내에 보관합니다.

현재 버전의 로그인 준비 안내

이번 1.4 제출 버전은 계정 화면에 ‘로그인 준비 중’ 안내만 표시합니다. Apple·카카오 로그인, 계정 생성, 기기 간 동기화, 로그인 상태 확인을 위한 서버 요청은 실행하지 않습니다. 서버 설정을 변경해도 이 버전의 로그인이 활성화되지 않으며 기능 제공에는 별도 앱 업데이트가 필요합니다.

개발을 위해 Supabase 공유 서버에 헬스앱용 저장소·인증 함수를 준비했지만, 이번 버전에는 서버 구성 파일과 Apple 로그인 권한을 포함하지 않습니다. 실제 로그인·동기화 출시 시 수집 항목·동의·인증·보관·삭제 처리와 정책을 다시 안내합니다.

04 보관과 삭제

운동 기록과 즐겨찾기는 앱 전용 저장 공간에 보관됩니다. 기기에서 앱을 완전히 삭제하면 해당 앱의 로컬 데이터도 삭제됩니다. 1.2 이상에서는 캘린더의 운동 상세 기록에서 ‘운동 기록 삭제’를 눌러 해당 세션의 시간·세트·심박수 최대값을 함께 지울 수 있습니다. 삭제한 기록은 늦게 도착한 워치 측정값으로 다시 생성되지 않습니다. 헬스장·슈퍼세트 설정은 각 목록에서 삭제할 수 있으며, 설정을 삭제해도 이미 완료된 운동 기록은 유지됩니다. 전체 초기화 기능은 제공하지 않습니다.

iOS의 ‘앱 정리하기’는 문서와 데이터를 남겨 두는 기능으로, 앱 완전 삭제와 다릅니다. 1.2 이상에서 심박수 최대값을 저장하면 이 값이 포함된 앱 운동 기록 폴더는 클라우드 백업 대상에서 제외되므로 기기 변경·재설치 시 자동 복원을 보장하지 않습니다. 기존 버전의 백업과 Apple 건강 앱이 별도로 관리하는 데이터는 사용자의 백업·건강 설정 및 Apple 정책에 따르며, 앱의 기록 삭제로 Apple 건강 앱의 데이터를 삭제하지 않습니다. 자세한 내용은 Apple의 앱 저장 공간 안내를 참고하세요.

개발자는 로그인하지 않은 기기 내 기록에 원격으로 접근하거나 대신 삭제할 수 없습니다. 이번 버전에는 서버에 저장되는 운동 기록이나 로그인 계정이 없습니다. 데이터 처리에 관한 문의는 아래 연락처로 보낼 수 있습니다.

05 제3자 제공과 외부 서비스

선택적 그래프 공유(1.4부터): 사용자가 직접 공유를 선택하면 선택한 기간·부위·종목의 날짜별 그래프 수치와 종목명을 이미지 또는 링크로 전달할 수 있습니다. 심박수 그래프를 선택한 경우 심박수 최대값도 포함됩니다. 공유 전에 안내하며 자동 공유하지 않습니다. 카카오톡 등 선택한 공유 서비스의 처리에는 해당 서비스 정책이 적용됩니다. 링크의 그래프 값은 URL의 # 뒤에 포함되어 브라우저에서만 해석되며 GitHub Pages 서버에는 전송되지 않습니다. 별도 그래프 데이터 서버나 분석 도구는 사용하지 않습니다. 링크를 받은 누구나 내용을 볼 수 있으며 전달된 링크·이미지를 개발자가 회수하거나 원격 삭제할 수 없습니다. 브라우저 방문 기록과 공유받은 서비스에 링크가 남을 수 있습니다. 공유 페이지 접속 시 GitHub가 처리하는 접속 정보는 아래 항목을 참고하세요.

이번 버전은 소셜 로그인·개발자 서버 전송을 하지 않으며 운동 기록을 광고 목적으로 판매·공유하거나 광고 추적 기능을 사용하지 않습니다.

App Store·TestFlight 및 사용자가 허용한 Apple의 진단·기기 백업 서비스에서 처리하는 정보에는 Apple의 정책과 사용자의 시스템 설정이 적용됩니다.

운동법 참고 링크를 누르면 Gains Lab 티스토리(noobgains.tistory.com)로 이동하며, 해당 사이트의 쿠키·접속 정보 처리는 티스토리의 정책을 따릅니다. 운동 기록은 이 링크에 포함해 전송하지 않습니다.

개인정보처리방침 링크나 이메일 문의 링크를 사용하면 웹 브라우저 또는 이메일 앱으로 이동합니다. 해당 서비스의 정보 처리는 각 서비스의 정책을 따릅니다.

06 이메일 문의

사용자가 직접 이메일을 보내는 경우, 발신 이메일 주소와 사용자가 작성한 문의 내용·첨부파일은 문의 확인, 답변과 문제 해결에 사용합니다. 이메일 문의는 선택 사항이며 앱 이용을 위한 필수 조건이 아닙니다.

문의 정보는 문의 대응에 필요한 기간 동안 보관하며, 대응이 끝나 더 이상 보관할 필요가 없는 정보는 삭제합니다. 문의 내용의 삭제 등 관련 요청도 아래 이메일로 접수합니다. 문의할 때 운동 기록이나 민감한 정보를 불필요하게 첨부하지 않아도 됩니다.

07 이 웹페이지의 접속 정보

이 개인정보처리방침은 GitHub Pages에서 제공합니다. 페이지에는 자체 광고·분석 스크립트, 추적 쿠키 또는 정보를 전송하는 문의 양식을 사용하지 않습니다.

웹페이지를 방문하면 GitHub가 보안 목적으로 방문자의 IP 주소를 기록·보관합니다. 이는 앱에서 운동 기록을 수집하는 것과 별개이며, 자세한 사항은 GitHub Pages의 접속 정보 안내와 GitHub 개인정보처리방침을 참고하세요.

08 방침 변경

앱 기능이나 개인정보 처리 방식이 달라지면 이 페이지와 최종 수정일을 갱신합니다. 새로운 정보 수집이나 외부 전송 기능을 도입하는 경우에는 변경된 방침에 해당 내용을 안내합니다.
